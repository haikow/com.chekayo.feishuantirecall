# fuck lark · 飞书增强模块（LSPosed）

飞书 / Lark / 飞书二次开发版增强模块，多功能合一。支持：
- **国内版飞书** `com.ss.android.lark`
- **国际版 Lark** `com.larksuite.suite`
- **飞书二次开发版**：自动适配理想、赛力斯等基于飞书定制的企业内部沟通工具，LSPosed 勾选作用域即用

设置页内注入开关面板，各功能独立开关。

> ⚠️ 仅供学习研究与个人使用，使用风险自负。native 原生层实现，不依赖飞书混淆名，跨版本稳定。**arm64**。

## 功能

### ① 消息防撤回
让被撤回的飞书消息原文继续显示 —— **包括你从未打开过的聊天**。
- **原生 SQL 层**：inline hook `libsqlcipher` 的 `sqlite3_step`，撤回写库时把撤回行的 `id` 与 `cid` 双改绑成唯一值 → 原文行不被覆盖 → 原文保留 + 生成持久「撤回了一条消息」提示，二者并存。
- **与飞书版本无关**：拦的是稳定的 SQL 存储层，不依赖混淆类名。**7.70.x / 7.71.8 / 国际版 7.72.10 实测通过**（冷重启后撤回原文仍在）。
- Java 映射器兜底为**版本自适应**：旧版（≤7.70）走原映射，新版纯走 native SQL 层。

### ② 离职同事统计
飞书同事离职后资料页被清空、也不知道谁离职了。本功能在**数据被清前**于本地库快照，累计记录离职名单（姓名 / uid / 离职时间），只增长归档。多账号自动分别采集、按 id 去重合并。

**怎么用（重要）**：本功能靠飞书**读本地通讯录库**时顺手快照，所以要**手动触发一次**——
1. 打开飞书 →【通讯录】→【组织架构 / 我的部门】；
2. **上下滑一圈**（让飞书把组织成员加载进本地库，模块随即抓取 `is_resigned` 快照）；
3. 回到 设置 →「🐱 fuck lark 设置」→**查看离职名单**，即可看到已离职同事。
> 之后每有同事离职，进一次【通讯录→组织架构】滑一下，就会**增量存档**（只增不减，飞书日后清了本地记录也不丢）。多账号请分别在各账号下滑一次。

**名单查看**：
- **顶部搜索框**：按 姓名 / 部门 / 邮箱 / 工号 / 职务 实时过滤。
- **按离职时间（飞书 `update_time`）新→旧排序**，每行显示离职日期，7 天内标 🆕。
- 点姓名跳转其资料页 / 聊天。
> 说明：名单来自飞书自身的 `is_resigned=1` 标记，判定权在飞书。若某人被误列，多因飞书本地记录陈旧（其 `update_time` 停在较早日期，是那时的状态被缓存）——以行内显示的离职日期为准自行判断。

### ③ 资料归档
你**打开过谁的资料页**，就把 TA 的完整档案（部门 / 企业邮箱 / 工号 / 职务 / 直属上级）归档到本地，离职后仍可查。配合富列表 UI，点名字可跳转其资料页 / 聊天。

### ④ 防对方已读 · 回复才已读（实验）
你**只看不回**时对方一直显示「未读」；只有你**回复**后，才把可视范围的消息标记为已读 —— 更自然、不易被察觉（复刻 Windows 吾乐吧行为）。私聊、群聊都覆盖。
- 设置面板开关，**默认关闭**。
- 已知局限：若你**一直停在聊天页面很久、不退出直接回复**，飞书可能不再触发已读上报 → 偶发仍显示未读，**退出会话再进去回复**即可。常见的「收到通知→点开→回复」不受影响。

### ⑤ 保留被踢群聊天记录（实验）
被移出群聊时，飞书会清掉你本地的群聊天记录。本功能在 SQL 层拦下清群/删消息，让**本地记录不被清除**，并**自动导出**该群聊天记录。
- 设置面板 **📤 被踢群聊天记录**：按群名 / 消息内容**搜索**，点开是**聊天样式**（发送人昵称 · 时间 · 气泡，系统消息如「A 邀请了 B」），可**复制 / 分享**。
- 说明：被踢后飞书 UI 不允许再进入该群（判定在底层），故走「本地保留 + 导出查看」。设置面板开关，**默认关闭**。

### ⑥ 退群 / 被移出提醒（实验）
默认情况下，**别人退群 / 被移出群聊，普通成员在飞书里是看不到的**（只有管理员能看到）。本功能让你也能看到：
- **群内持久显示**：「移出」系统消息像正常「入群」提示一样**显示在群聊天窗里**（原生样式、常驻）。
- **Toast 提醒**：有人退群 / 被移出你所在的群时，实时弹出「X 被 Y 移出群聊『群名』」。
- **记录存档**：设置面板 **👋 退群/移除记录** 持久保存，可复制 / 清空。
- 设置面板开关，**默认关闭**。

### 诊断日志（排查用）
反馈「防撤回不生效」时开启此开关 → 重启飞书复现 → 面板「🧾 查看诊断日志」一键复制发作者。**默认关闭，不写任何文件。**

### 设置面板
飞书「设置」页内注入「🐱 fuck lark 设置」入口，弹出开关面板：各功能开关（防撤回 / 离职统计 / 防对方已读 / 保留被踢群 / 退群提醒 / 诊断日志）+ 离职名单查看 + 被踢群记录 + 退群/移除记录 + **💬 加入讨论群（Telegram）**。

## 安装

1. LSPosed 中启用本模块，作用域勾选你的飞书 app：
   - **国内版飞书** `com.ss.android.lark`
   - **国际版 Lark** `com.larksuite.suite`
   - **飞书二次开发版**（理想、赛力斯等企业内部沟通 app）：勾选该 app 即可，模块自动适配。
2. 重启目标 app 生效。
3. 目标 app 设置页 →「🐱 fuck lark 设置」调开关。
