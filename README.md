# fuck lark · 飞书增强模块（LSPosed）

飞书 / Lark / 飞书二次开发版增强模块，多功能合一。支持：
- **国内版飞书** `com.ss.android.lark`
- **国际版 Lark** `com.larksuite.suite`
- **飞书二次开发版**：自动适配理想、赛力斯等基于飞书定制的企业内部沟通工具，LSPosed 勾选作用域即用

设置页内注入开关面板，各功能独立开关。

> ⚠️ 仅供学习研究与个人使用，使用风险自负。native 原生层实现，不依赖飞书混淆名，跨版本稳定。**arm64**。

💬 讨论群（Telegram）：<https://t.me/fucklark>（模块设置面板内也有一键入口）

## 功能

### ① 消息防撤回
让被撤回的飞书消息原文继续显示 —— **包括你从未打开过的聊天**。
- **原生 SQL 层**：inline hook `libsqlcipher` 的 `sqlite3_step`，撤回写库时把撤回行的 `id` 与 `cid` 双改绑成唯一值 → 原文行不被覆盖 → 原文保留 + 生成持久「撤回了一条消息」提示，二者并存。
- **与飞书版本无关**：拦的是稳定的 SQL 存储层，不依赖混淆类名。**7.70.x / 7.71.8 / 国际版 7.72.10 实测通过**（冷重启后撤回原文仍在）。
- Java 映射器兜底为**版本自适应**：旧版（≤7.70）走原映射，新版纯走 native SQL 层。

### ② 离职同事统计
飞书同事离职后资料页被清空、也不知道谁离职了。本功能在**数据被清前**于本地库快照，累计记录离职名单（姓名 / uid / 离职时间），只增长归档。多账号自动分别采集、按 id 去重合并。

**怎么用（重要）**：本功能靠飞书**读本地通讯录库**时顺手快照，所以要**手动触发一次**——
1. 打开飞书 →【通讯录】→【组织架构 / 我的部门】；
2. **上下滑一圈**（让飞书把组织成员加载进本地库，模块随即抓取 `is_resigned` 快照）；
3. 回到 设置 →「🐱 fuck lark 设置」→**查看离职名单**，即可看到已离职同事。
> 之后每有同事离职，进一次【通讯录→组织架构】滑一下，就会**增量存档**（只增不减，飞书日后清了本地记录也不丢）。多账号请分别在各账号下滑一次。

**名单查看**：
- **顶部搜索框**：按 姓名 / 部门 / 邮箱 / 工号 / 职务 实时过滤。
- **按离职时间（飞书 `update_time`）新→旧排序**，每行显示离职日期，7 天内标 🆕。
- 点姓名跳转其资料页 / 聊天。
> 说明：名单来自飞书自身的 `is_resigned=1` 标记，判定权在飞书。若某人被误列，多因飞书本地记录陈旧（其 `update_time` 停在较早日期，是那时的状态被缓存）——以行内显示的离职日期为准自行判断。

### ③ 资料归档 · 全员档案（自动批量）
飞书把你浏览过的同事完整资料缓存在本地（`chatter_profiles_v3`），本模块**自动批量解析归档**，不再需要逐个点开资料页：
- **部门 / 企业邮箱 / 工号 / 职务 / 直属上级 / 手机号** 一次性入库；离职后飞书清空其资料，你的存档仍在（**只增不删**）。
- **本公司 / 外部客户自动区分**：按租户识别，外部群 / 客户群里的人也记录（姓名 / 群昵称 / 所属公司名）。
- 设置面板 **📇 全员档案**：搜索（姓名 / 部门 / 邮箱 / 工号 / 职务 / 手机 / 公司）、本公司在前、🏢 本公司 / 🌐 外部分色、点行跳资料页 / 聊天，顶部有操作说明 + 实时统计。
- **想收全**：进【通讯录 → 组织架构】把各部门展开、上下滑到底，让飞书加载资料，模块随即自动存档；覆盖率随使用增长。
> 手机号：仅**你自己**的完整可见，其他人飞书服务端已打码（形如 `+86-1XX****XXXX`），本地拿到的即打码值。
> 「打开资料页即归档」作为兜底仍保留（补少数不在本地缓存的人）。

### ④ 防对方已读 · 回复才已读（实验）
你**只看不回**时对方一直显示「未读」；只有你**回复**后，才把可视范围的消息标记为已读 —— 更自然、不易被察觉（复刻 Windows 吾乐吧行为）。私聊、群聊都覆盖。
- 设置面板开关，**默认关闭**。
- 已知局限：若你**一直停在聊天页面很久、不退出直接回复**，飞书可能不再触发已读上报 → 偶发仍显示未读，**退出会话再进去回复**即可。常见的「收到通知→点开→回复」不受影响。

### ⑤ 保留被踢群聊天记录（实验）
被移出群聊时，飞书会清掉你本地的群聊天记录。本功能在 SQL 层拦下清群/删消息，让**本地记录不被清除**，并**自动导出**该群聊天记录。
- 设置面板 **📤 被踢群聊天记录**：按群名 / 消息内容**搜索**，点开是**聊天样式**（发送人昵称 · 时间 · 气泡，系统消息如「A 邀请了 B」），可**复制 / 分享**。
- 说明：被踢后飞书 UI 不允许再进入该群（判定在底层），故走「本地保留 + 导出查看」。设置面板开关，**默认关闭**。

### ⑥ 退群 / 被移出提醒（实验）
默认情况下，**别人退群 / 被移出群聊，普通成员在飞书里是看不到的**（只有管理员能看到）。本功能让你也能看到：
- **群内持久显示**：「移出」系统消息像正常「入群」提示一样**显示在群聊天窗里**（原生样式、常驻）。
- **Toast 提醒**：有人退群 / 被移出你所在的群时，实时弹出「X 被 Y 移出群聊『群名』」。
- **记录存档**：设置面板 **👋 退群/移除记录** 持久保存，可复制 / 清空。
- **静默退群也抓**：公司里同事**离职自动退群不会广播系统消息**（只悄悄删成员），本功能也会检测并记录**是谁离开了哪个群**（写入 👋 退群/移除记录，不弹 Toast 以免批量刷屏）。注：只记开启后新发生的；离职者名字若已被飞书清空则显示 id。
- 设置面板开关，**默认关闭**。

### ⑦ 组织架构自动巡游（配合资料归档收全公司）
资料归档要「进通讯录滑到底」才收得全，部门多时手动滑很累。本功能用无障碍服务**自动**走遍整棵组织架构树：
- 系统「无障碍」里开启「fuck lark 组织巡游」后，进【通讯录 → 组织内联系人】即自动 DFS 逐部门进入、滑到底，逼飞书把全员懒加载进本地库，归档随即批量抓取。
- **音量键停止**：巡游中按【音量+ / 音量-】即可暂停（巡游时 UI 被接管，比开面板方便）。
- **断点续跑**：暂停后到设置点「▶️ 继续巡游」，再进组织架构页从中断的部门接着走。
- 设置面板 **🧭 组织架构自动巡游** 开关（镜像系统无障碍状态）+ 停止 / 继续 / 从头开始子项。
> 仅作用于飞书；无障碍权限只用于驱动此巡游。arm64。

### ⑧ 后台消息存档（防「后台撤回」）
①的 SQL 层防撤回对付「你在线时」的撤回；但**后台/离线时对方撤回**，服务器只下发「已撤回」空壳、**原文根本不发到你本地库**，SQL 层无从拦起。此时原文只在**通知**里出现过一次。本功能就抓这个：
- hook 通知，普通消息先进内存缓冲；收到「X 撤回了一条消息」时，按发送人**回捞那条原文、只把被撤回的落盘**（普通消息不记，干净）。
- 设置面板 **📨 后台消息存档** 查看（时间 / 发送人 / 原文）；对应开关**默认关闭**。
- **前提**：飞书通知里开着「消息预览」（否则通知没正文，无从抓取）；仅文本可靠。

### 诊断日志（排查用）
反馈「防撤回不生效」时开启此开关 → 重启飞书复现 → 面板「🧾 查看诊断日志」一键复制发作者。**默认关闭，不写任何文件。**

### 设置面板
飞书「设置」页内注入「🐱 fuck lark 设置」入口，弹出开关面板：各功能开关（防撤回 / **📨 后台消息存档** / 离职统计 / 防对方已读 / 保留被踢群 / 退群提醒 / **🧭 组织架构自动巡游** / 诊断日志）+ 离职名单查看 + **📇 全员档案** + 被踢群记录 + 退群/移除记录 + **💬 加入讨论群（Telegram）**。

## 安装

1. LSPosed 中启用本模块，作用域勾选你的飞书 app：
   - **国内版飞书** `com.ss.android.lark`
   - **国际版 Lark** `com.larksuite.suite`
   - **飞书二次开发版**（理想、赛力斯等企业内部沟通 app）：勾选该 app 即可，模块自动适配。
2. 重启目标 app 生效。
3. 目标 app 设置页 →「🐱 fuck lark 设置」调开关。

## 遇到问题怎么反馈

隔空排查全靠你给的信息，只说「用不了」定位不了。发之前先自查：模块**已启用**且**作用域勾了你在用的飞书**、改完作用域**重启过飞书**、手机是 **arm64**、面板里对应开关**开着**——多数问题到这就好了。

还不行就照下面填，一次基本能定位：

```
手机 / 系统：小米 13 Ultra，MIUI 14.0.17（Android 13）
飞书版本：7.71.8（国内版 / 国际版 Lark / 公司二开版）
模块版本：1.6.6
安装框架：LSPosed / LSPatch / 太极
哪个功能没生效 + 具体现象：防撤回——对方撤回后仍不显示原文
诊断日志：面板「🧾 查看诊断日志」开开关 → 重启飞书复现 → 一键复制附上
```

> 诊断日志默认不开、不落文件，只记版本 / hook 是否装上 / 撤回有没有拦到，**不碰聊天内容**。
